# VILE for Android

Исторический архив **VILE for Android** — Android-порта движка визуальных новелл **ViLE (Visual Library Engine)**, созданного в 2015–2016 годах разработчиком, известным под именем «Иван».

Готовое приложение распространялось через сообщество «Визуальные новеллы для Android» — чейнджлог порта сохранился в [архивной теме VK](https://vk.ru/topic-69564393_33447386). Исходный код тоже был выложен — на Яндекс Диске, — но со временем ссылка на него стала неактивной: по-видимому, автор почистил диск. Сохранившаяся в частном архиве копия публикуется здесь в исторических целях. Код импортирован как есть, без чистки и правок, в том виде, в каком он остался к началу 2016 года.

> **Статус:** архив. Разработка этой версии прекращена и не возобновится, код не сопровождается. Действующий Android-порт движка — [IkuraDroid](https://github.com/VienDesuPorting/ikuradroid).

English version: [README.en.md](README.en.md)

## История

ViLE — открытый кроссплатформенный движок для запуска японских визуальных новелл, поддерживающий несколько фирменных скриптовых форматов.

В 2015–2016 годах на его основе был написан Android-порт: ядро ViLE 0.4.13, нативная часть поверх SDL 2.0.3 и Java-обвязка на основе SDLActivity. Проект собирался в Eclipse/ADT со сборкой через Apache Ant и был рассчитан на устройства своей эпохи.

После прекращения работы над портом его исходники сохранились в частном архиве — и позднее именно они стали основой нового Android-плеера визуальных новелл, IkuraDroid. Здесь опубликован первоначальный код, из которого всё началось.

## Техническая информация

| Параметр | Значение |
|---|---|
| Версия ядра | ViLE 0.4.13 |
| Версия приложения | 1.0 (в меню — «Vile 0.54») |
| Минимальная версия Android | API 8 |
| Целевая платформа | Android API 23 |
| Архитектура | ARMv7 (`armeabi-v7a`) |
| Графика и мультимедиа | SDL 2.0.3 |
| Инструменты сборки | Eclipse ADT / Apache Ant |

## Состав проекта

### Игровые движки

Ядро ViLE 0.4.13 с движками исходных семейств:

- Crowd
- C-Ware
- Ikura GDL
- JAST
- T-Love
- Will
- Windy

Поверх них — собственные модули порта: **Ikura Heartdr** и **Ikura Virgin** (семейство Ikura), **Will Princess** и **Will Starry** (семейство Will).

### Нативная часть

- `jni/vile/` — ядро ViLE и игровые движки;
- `jni/Vile.cpp` — JNI-обвязка между ядром и Java;
- `jni/vile/media/hh/` — аудио- и видеобэкенды порта;
- `jni/vile/common/edl_texture.*` — работа с текстурами;
- `jni/vile/external/hq2x`, `hq3x`, `hq4x` — алгоритмы масштабирования изображения.

### Сторонние библиотеки

В `jni/` лежат вендоренные исходники всего необходимого для нативной сборки:

- SDL 2.0.3
- SDL_image 2.0.0
- SDL_mixer 2.0.1
- SDL_ttf 2.0.14
- SDL_gfx
- libmikmod 3.1.12
- SMPEG2 2.0.0
- libwebp

## Сборка и совместимость

Проект сохранён в историческом состоянии и не адаптировался под современные инструменты разработки. Для сборки своей эпохи требовались:

- Eclipse с ADT и Apache Ant;
- Android SDK (target android-23);
- Android NDK со статической библиотекой `gnustl_static`;
- внешние библиотеки `android-support-v7-appcompat`, `cardview` и `recyclerview`, на которые ссылается `project.properties` — самих библиотек в репозитории нет.

Сборка из чистой копии современными средствами не гарантируется. Наличие исходников и готового APK не означает совместимость с актуальными версиями Android: минимальный поддерживаемый API — 8, целевой — 23, нативная часть — только `armeabi-v7a`.

Скомпилированная историческая версия лежит в `bin/Vile.apk`.

## Продолжение проекта

Развитие Android-порта движка продолжилось в [IkuraDroid](https://github.com/VienDesuPorting/ikuradroid) — именно из этого кода он и вырос. IkuraDroid переведён на современный инструментарий (Gradle, актуальные SDK/NDK), его Java-часть полностью переписана, а поддержка семейств визуальных новелл постепенно расширяется.

Этот репозиторий хранится отдельно, чтобы первоначальный порт оставался доступным для изучения и сравнения.
